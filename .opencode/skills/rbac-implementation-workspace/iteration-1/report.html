Key Observations

  • Both configurations passed 100% — the RBAC model doc is detailed enough that even without the skill, agents produce correct code.
  • With-skill outputs were more structured — migration followed the doc's section numbering exactly, each policy referenced the section it came from.
  • With-skill was faster (-4.3s avg) and used fewer tokens (-4K avg) — the skill's reference files provided ready-made patterns that saved the agent from reinventing the structure.
  • Without-skill went broader — added per-page useRequireRole() to individual page components (14 files changed), while with-skill kept it DRY at the layout level.
  • The skill's main value is ensuring completeness (every referenced table is covered, every nav route is mapped), structuring output to match the doc, and following existing code conventions automatically.
