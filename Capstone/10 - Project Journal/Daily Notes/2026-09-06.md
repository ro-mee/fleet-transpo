### Fix — SystemHealthCard crashed on healthy render (my key-mapping bug)

Right after wiring, the dashboard threw `Cannot read properties of undefined
(reading 'tile')` at `SystemHealthCard`. Root cause was mine: I keyed the
tone map by color (`rose/amber/emerald`) but indexed it by level
(`degraded/attention/healthy`) — healthy renders hit `undefined`. (curl
checks passed because the crash happens in the authenticated client render,
not the shell HTML — lesson: curl cannot catch client-render crashes.)
Fix: keys renamed to level names, plus the lookup extracted to exported pure
`healthToneClasses()` with an attention-amber fallback for garbage input
(never green, never undefined), pinned by
`system-health-card.test.js` (5 tests: full class set per level, distinct
dots, garbage fallback). Verified: 5/5 pass, eslint clean, dashboard HTTP 200.
