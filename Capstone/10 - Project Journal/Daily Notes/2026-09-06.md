### Pass 1a — app_errors foundation (code + migration, no API/UI yet)

Locked ownership contract with the user: `app_errors` owns *unexpected*
failures; specialized subsystems own expected operational failures. Gate is
proof-of-persistence (`subsystemOwned === true` set only after the
specialized write succeeds) — a bare subsystem code never suppresses, so a
failed specialized write still lands centrally as fallback.

- **Audit first:** `llm-adapter` needed no change (logs `ailogs` Error +
  returns fallback, never throws). Two real gaps found: `scan-document` and
  driver `license-scan` contained Gemini failures with `console.warn` only
  (persisted nowhere) — both inner catches now write
  `logAiRequest({ status: "Error", ... })` before the manual-entry fallback.
  Other AI routes use never-throwing adapters, so their catches see only real
  bugs → correctly eligible for `app_errors`. No route-prefix exclusion.
- **`src/lib/app-errors.js` (new):** `sanitizeErrorText` (Bearer/cookie/auth-
  header redaction, URL→pathname, secret assignments),

  `SUBSYSTEM_OWNED_CODES` (classification only), `normalizeContext` +
  `requestContext` (pathname + UA, never re-runs auth),
